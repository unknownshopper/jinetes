Sistema POS a la Medida

Control Total Centralizado para "Los de Costilla"

Presentado a: Sr. Miguel León e Hijos

Alcance: Sucursal Tamulté & Sucursal Atasta

Actualización: Posterior a reunión operativa (matriz) — Septiembre 2026

Objetivo operativo (dolor real)

Operar desde matriz con control total en el celular: ventas, inventario, alertas por sucursal y reportes, sin depender de estar físicamente en cada punto.

Comandero

Captura rápida desde celular con pocos clicks: comer aquí / llevar / domicilio, +/− por producto y cierre de venta.

Demo: comand.html

Ventas / Status

Tablero global con switch 1/2 sucursal, top vendidos con barras, ritmo por hora y vista "Don Miguel".

Demo: ventas.html

Inventario / Alertas

Inventario por sucursal con mínimos, alertas antes de crítico y movimientos (log). Recetas/consumo automático queda como módulo.

Demo: inventario.html

Módulos opcionales (cotización aparte)

  • WhatsApp API para envío automático de resumen / alertas (requiere configuración y costos por conversación).
  • Didi / UberEats: captura de folio y conciliación (extra).
  • Recetas & consumo automático (por gramos/piezas) + mermas (extra).
  • Pagos con tarjeta (Clip): módulo y flujo de cobro (extra).
  • Marketing / clientes: base de datos, campañas y cupones (extra).

Equipamiento del MVP (Mínimo Producto Viable)

Para arrancar de inmediato sin inversiones infladas, cada sucursal (Tamulté y Atasta) requiere la siguiente infraestructura tecnológica básica para captura e impresión:

Método de Captura Principal

Celular medio uso o gama media.

Vista web para capturar las órdenes de los clientes.

1 Unidad por Sucursal

Impresora Térmica de Tickets de Venta (Comprobante)

Tiquera térmica de 80mm con conexión Bluetooth / WIFI.

1 Unidad por Sucursal

Celular para Reparto (si aplica domicilio)

Celular medio uso o gama media (para capturar dirección / referencia).

*No es indispensable si el reparto lo gestiona la sucursal con WhatsApp manual.

Opcional

Nota de desarrollo: El código HTML/JS se comunicará de manera nativa con las tiqueras mediante protocolos de impresión estándar (ESC/POS) asegurando rapidez en el despacho.

Ventaja Tecnológica Exclusiva

Al desarrollar usando la arquitectura de Firebase, si el internet de Atasta o Tamulté falla momentáneamente, las cajas pueden seguir registrando pedidos. El sistema se sincronizará automáticamente con la nube en cuanto regrese la señal, garantizando que el negocio nunca se detenga.
